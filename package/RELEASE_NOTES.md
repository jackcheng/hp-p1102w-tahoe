The same HP LaserJet Professional P1102w driver as before, with the macOS version check removed from the installer. It installs on macOS 26 (Tahoe), macOS 27, and later releases instead of stopping with a "can't be installed on this version of macOS" error.

**Install:** download `HP_P1102w_macOS_Driver.pkg` below and double-click it. If macOS blocks it, open **System Settings > Privacy & Security**, scroll down to **Security**, click **Open Anyway**, and confirm. Full steps are in the [README](https://github.com/jackcheng/hp-p1102w-tahoe#installation).

`HP_P1102w_macOS_Driver.pkg.sha256` holds the checksum if you want to verify the download.
